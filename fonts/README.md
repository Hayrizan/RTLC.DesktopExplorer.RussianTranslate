# Шрифты русской локали

Файлы предоставлены пользователем без изменения бинарного содержимого.

| Файл | Автор | Заменяет |
|---|---|---|
| PixeloidSans.ttf | GGBotNet | Windows Regular |
| PixeloidSans-Bold.ttf | GGBotNet | Windows Bold |
| PixeloidMono.ttf | GGBotNet | Windows Monoline |
| MatrixSans-Regular.ttf | The Matrix Sans Project Authors / Brad Neil | BPdotsSquares Bold |

Лицензия: SIL Open Font License 1.1. См. OFL-Pixeloid.txt и OFL-MatrixSans.txt. Шрифты принадлежат указанным авторам. Игровые исходные шрифты сюда не включены.

Плагин загружает TTF из этой папки и создаёт TMP-атласы в памяти; устанавливать шрифты в Windows не нужно. Эффектные варианты Glitch, Tower и Colorlens берут материалы из установленной игры. Контрольные суммы предоставленных TTF и проверка cmap — в reports/replacement-fonts.json архива.
